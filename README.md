# PowerPoint RPG

An RPG made in PowerPoint. Hyperlinks and slide transitions drive a health bar, levelling, skills and NPCs that hand out quests.

## How to play

Download from Releases and run it, and it starts straight into the slideshow. PowerPoint or PowerPoint Viewer must be installed. Opening `source/powerpoint-rpg.ppt` and pressing F5 works too.

Everything is controlled with the mouse. Click the buttons and shapes on screen to move on.
